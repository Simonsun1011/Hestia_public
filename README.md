# Infans Studio · Hestia 改版

一个跑在自己 Mac 上的个人工作台：项目、日程、学习、馆藏、宠物、价格、活动都写成本地 Markdown 文件，页面从文件读，AI Agent 也直接读写这些文件。适合拿来当底子，一边用一边让 AI 帮你改成自己的应用。

## 来源

本项目基于 **[Infans 小秘书](https://github.com/CapooFun/infans-xiaomishu)**（作者 CapooFun，MIT 许可）的清洁演示版修改。界面、主题、项目治理方式、学习体系和大部分模块都来自 Infans，感谢原作者开源。想看原版或跟进原作者的更新，请去原仓库。

在 Infans 的基础上，本仓库加了下面这些，做法多来自我自己的工作台 Hestia：

| 新增 | 在哪 | 做什么 |
|---|---|---|
| 宠物 | 一级入口「宠物」 | 档案、护理与就医、用品；体重曲线，快到期的驱虫和疫苗 |
| 价格追踪 | 实用工具 · 价格追踪 | 日亚、楽天、Yahoo!ショッピング 的指定商品与类别搜索，记录到手价走势，每天一次买不买的建议 |
| 东京活动自动采集 | 日程安排 · 日本活动 | 每周从官方来源页采集展览、音乐会、AI 活动；点「生成攻略」才生成出门攻略 |
| Token 统计 | 实用工具 · Token 统计 | 只统计 Claude：本机 Claude Code 会话与工作台后台任务，最近 5 小时 / 7 天 / 30 天 |
| 任务设置 | 实用工具 · 设置 | 后台任务的开关、每天或每周、时刻、全部暂停、模型选择、活动类别与入选标准 |
| 数据纪律 | `AGENTS.md`「数据纪律」 | 原件是资产、页面是耗材；一个文件一种出处；改判断留痕；写入护栏 |
| 测试 | `pnpm test` | 后台任务、锁、防重复提交、校验逻辑都有测试 |

后台 AI 任务的几条原则：

- **模型只摘录，不联网。** 网页由脚本抓取、转成纯文本交给模型；模型交回的价格、标题、链接必须逐字出现在网页原文里，否则丢弃。
- **模型在沙箱里跑。** 用 macOS `sandbox-exec` 禁止它读写工作台目录和 home 下的敏感目录，不给任何工具。
- **省额度。** 低级任务用 Haiku 并关掉思考，判断类任务才用 Sonnet；有调用次数与总时长上限；疑似额度用尽就停下，定时任务暂停 5 小时。20 美元的 Claude 订阅也够用。
- **不怕超时和重复点。** 单次调用、整次运行都有超时，超时杀掉整个进程组；同一任务连点、手机和 Mac 同时点，都只运行一次。

## 首次启动

需要 macOS、Node.js 22.13 或更高、pnpm。后台任务另需 [Claude Code](https://claude.com/claude-code) 并登录（终端里 `claude` 能用）。

```bash
cd 00_本地工作台/app
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:4178/`。工作台开着时，后台任务按设置的时刻运行；第一次启动不会补跑，不会一打开就花额度。

## 先看哪里

- `90_使用说明/Infans私人秘书使用说明.md`：第一次拿到后先做什么，以及每天怎样使用。
- `90_使用说明/宠物、价格追踪与东京活动.md`：新增功能的用法、数据格式、省额度与排障。
- `AGENTS.md`：任何 AI Agent 接手前必须遵守的规则，包括「数据纪律」。
- `00_本地工作台/app/`：React 工作台工程；`scripts/run-job.mjs` 是后台任务的唯一入口。
- `30_事业顺利/`、`50_语言学习/`、`60_艺术馆藏/`、`70_领域研究/`、`80_生活事务/`：各模块的原件与演示数据。


```bash

```

```bash

```

## 边界

- 所有人物、项目、日程、账单、资产、宠物都是虚构演示数据。
- 游戏封面、动漫封面和音乐样例是商业作品，不在仓库里；页面在没有封面时显示占位，功能照常。自己的游戏封面放进 `60_艺术馆藏/我的游戏/封面/` 即可（这个目录不进 git）。
- 后台任务的运行状态写在 `00_本地工作台/运行状态/`，不进 git。
- 不连接 NAS、券商、银行卡或任何购物、票务账号；不下单，不自动报名。
