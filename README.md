# Infans Studio

Infans Studio 是从原 Infans 工程直接复制、再逐项剔除和脱敏得到的 Mac 单机演示版。它保留原工作台的页面结构、主题、路由、项目治理方式、学习体系和主要交互，不是重新画的一套前端。

## 先看哪里

- `90_使用说明/Infans私人秘书使用说明.md`：第一次拿到后先做什么，以及每天怎样使用。
- `AGENTS.md`：任何本地 AI Agent 接手项目前必须遵守的自动登记、回写、验收、日志和安全规则。
- `00_本地工作台/app/`：原版 React 工作台的清洁工程。
- `30_事业顺利/`：小秘书和四个虚构事业项目的管理原件、完整功能 Wiki、大作战与网状任务示例。
- `50_语言学习/`：日语等非隐私学习内容。
- `60_艺术馆藏/`：游戏、动漫和书籍等演示馆藏。
- `70_领域研究/`：专题知识地图与学习内容。
- `90_使用说明/`：项目接入、AI Agent 协作、日记与日志、只读 MCP、学习闭环和备份方法。
- `90_使用说明/后台服务与自动化任务.md`：工作台常驻、每日日志收口、金融简报、异常雷达和其他不可见后台工作。
- 同级 `Infans_Support/`：动漫封面、音乐样例和金融资讯支持材料。

## 首次启动

```bash
cd 00_本地工作台/app
pnpm install
pnpm dev
```

浏览器打开终端给出的地址，默认是 `http://127.0.0.1:4178/`。

## 重要边界

所有人物、事业、日程、日志、账单、资产和持仓都是虚构演示数据。项目不连接 NAS、券商、银行卡、聊天模型或原作者的其他项目文件夹；不预装原作者的定时任务，也不包含聊天、人物关系、私人媒体与凭据。朋友可根据使用说明在自己的 Mac 上逐项启用通用后台任务。

开始填自己的内容前，先读 `90_使用说明/项目治理与新项目接入.md`，不要把工作台派生卡片当成第二份事实原件。
