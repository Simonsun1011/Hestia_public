# 凡人修仙传 · 动画

## 本人原始判断

> 我特别喜欢《凡人修仙传》动漫。《月蔷薇洋装》和《辞职修仙传》都在做它的“影子游戏”。我着迷于它精良的制作、丰富的人物情感、深刻而不教条的人生思考和道心追求；这些与我的精神很契合。我在哲学思想上也最贴近道学。

## 为什么重要

- 它不只是“喜欢的动画”，已经与两个现实游戏项目发生直接关系。
- 吸引力同时来自制作、人物情感、人生思考与道心追求，不是单一题材偏好。
- 它与 Studio User 的精神取向和道学亲近感相连，适合成为跨作品长期研究的核心来源。
