# 我的游戏

> **清洁版边界**：本目录保留馆藏框架、作品名称、平台分类和必要封面，用来展示艺术馆藏怎样工作。原拥有者的账号主页、账号 ID、真实时长、最近活动、成就统计、购买证据与个人经历均已移除。

## 模块卡

**定位**：分开管理“平台作品清单”和“游戏文化研究”，再由工作台把两类内容关联起来。

| 内容 | 权威位置 | 清洁版保留范围 |
|---|---|---|
| 平台馆藏 | [[steam_库.json]] · [[非Steam游戏.json]] · [[apple_games_库.json]] | 作品名、平台、公开元数据、必要封面 |
| 文化研究 | [[个人游戏文化谱系_总览]] · `文化谱系/*.md` | 中性研究框架与示例问题 |
| 工作台视图 | 艺术馆藏游戏页 | 搜索、筛选、平台分栏与详情展示 |

平台清单不证明新拥有者实际拥有或玩过这些作品，也不能自动生成喜欢程度或个人判断。

## 数据使用方式

1. 把 JSON 视为可替换的数据源，不把清洁版样例当成自己的真实馆藏。
2. 新拥有者可逐步删除样例条目，换成自己确认过的作品。
3. 个人评价应单独写入文化卡；不要由时长、评分或平台状态自动推导。
4. 若以后接入平台 API，只保存展示真正需要的字段，并继续排除账号 ID、主页地址和可识别活动轨迹。
