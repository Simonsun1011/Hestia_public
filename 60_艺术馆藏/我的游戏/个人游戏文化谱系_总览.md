# 游戏文化谱系

## 模块卡

**定位**：记录作品为何重要、哪些设计值得研究，以及它可能怎样影响创作；不做通用百科，也不保存原拥有者的私人回忆。

| 组件 | 位置 | 作用 |
|---|---|---|
| 平台馆藏 | [[steam_库.json]] · [[非Steam游戏.json]] · [[apple_games_库.json]] | 提供作品名与平台等公开元数据 |
| 文化卡 | `文化谱系/*.md` | 保存研究问题、来源和以后由拥有者填写的判断 |
| 模板 | [[游戏文化卡_模板]] | 统一记录结构 |
| 工作台 | 艺术馆藏游戏页 | 把作品、文化卡和全文阅读连起来 |

## 新拥有者怎样使用

1. 先从一部真正熟悉的作品开始，不追求一次补全全部经历。
2. 写下自己的原话：喜欢什么、不喜欢什么、最难忘什么。
3. 把可核验的外部资料和主观判断分开记录。
4. 需要 AI Agent 协助时，让它查资料、整理问题和结构，但不要替本人虚构感受。
5. 当某条判断真的进入设计或创作，再链接到对应事业项目的功能 Wiki 或任务。
