# 小秘书 · 产品功能树

> 结构直接来自正式 Infans 的“总索引 + 模块原件”。这里只移除不分享的私密能力；保留条目的功能说明与层级正文不再压缩。

## 使用规则

- 功能按“大模块 → 小模块 → 功能分组 → 具体行为”逐层展开。
- 任务、阻塞、完成与验收事实仍由项目的 `项目进度与待办.md` 单写，通过稳定 ID 多对多关联到功能。
- 清洁版页面、资产、日志和项目均使用假数据；接入真实资料前必须由项目拥有者重新审核。
