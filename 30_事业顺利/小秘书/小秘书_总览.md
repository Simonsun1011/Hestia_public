# 小秘书

小秘书是 Infans Studio 本身，也是这套演示工程的主项目。它把 Markdown 原件、外部项目接口、学习记录、日程和本机工具汇总成派生视图，但不把看板当成第二份事实原件。

## 这一版保留什么

- 与正式工作台一致的首页、日程、事业、学习、研究、馆藏、资产和工具界面。
- 项目注册表 → 项目自己的 `项目进度与待办.md` → 工作台派生视图这一条治理链。
- 新项目接入的稳定 ID、总览、进度原件与外部工程接口。
- GPT 负责自由教学与讨论，本地 AI Agent 负责核验结构、更新原件、运行检查的学习闭环。
- 工作日志、演示对话日志、异常雷达、本地音乐库和续费到期。

## 不进入演示版

- 真实身份、账号、银行卡、账单、凭据、住址和设备信息。
- 个人兴趣、关系记忆、即时通讯组件及其历史附件。
- 真实 NAS、自动备份定时任务和任何外部项目的私有仓库内容。

## 新项目如何接入

1. 从 `90_使用说明/模板/事业项目模板/` 复制最小项目目录。
2. 给项目一个稳定 `projectId`，在 `事业顺利_总览.md` 登记入口。
3. 项目事实只写在该项目的 `项目进度与待办.md`；外部代码仓只登记路径和接口。
4. 运行工作台检查，确认事业页、日程与首页都能读到同一份状态。

产品模块、功能能力与成熟度见 [[30_事业顺利/小秘书/产品功能树|小秘书产品功能树]]；项目任务、阻塞、完成和验收仍只在项目进度原件维护。

## 学习闭环

GPT 可以按知识地图讲解日语或专题，输出带稳定节点的学习报告；本地 AI Agent 接票后检查重复、来源与状态，再把报告放回对应知识节点。演示版保存方法与样例，不连接任何人的真实聊天记录。
