# 活动来源

「日程安排 · 日本活动」按这里列出的来源页自动采集，由模型按各类别的 criteria 摘录，脚本再核对标题、链接、价格确实出自页面。

- `categories` 是可勾选的类别；勾选哪些、各类别的入选标准、每周什么时候采集，在「实用工具 · 设置」里改。
- `sources` 是来源页，`categories` 写该来源可能出现的类别。来源越多，每次采集用的 token 越多。
- 来源页必须是脚本能直接抓到的静态页面；靠 JavaScript 渲染的站点抓不到活动。
- `hosts` 可选，缺省取 url 的主机；页面里只有落在 hosts 内的链接才被认作活动链接。
- `max_chars` 可选（5000–60000），交给模型的页面文字上限，缺省 30000。
- 加来源、改类别直接编辑本文件，下次采集生效。
