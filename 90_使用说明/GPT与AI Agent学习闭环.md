# GPT 与 AI Agent 学习闭环

## 分工

GPT 负责自然对话、自由讲解、追问、例句和小测；本地 AI Agent 负责读取真实知识地图、确认节点 ID、核查来源、去重、更新学习状态并运行工程检查。两者都不能把“聊过”直接当成“掌握”。

## 一次学习的流程

1. 从日语或专题页选择一个已有节点；没有节点时先创建候选，不随意造重复主题。
2. 让 GPT 围绕节点讲解，并要求给出：节点 ID、学习目标、关键结论、例子、仍不确定的地方和自测结果。
3. 把完整学习报告交给本地 AI Agent；不要只转发一句总结。
4. AI Agent 核对节点是否存在、报告是否重复、结论是否有来源、自测是否足以支持状态变化。
5. 通过后写回对应知识节点或学习记录；未通过则保留为草稿或待核实项。
6. 工作台读取更新后的原件，显示进度、最近学习和下一步。

## 日语建议

- 单词、文法、阅读、考试练习分别记录，不用总学习时长代替掌握证据。
- GPT 可以做角色对话和纠错；本地 AI Agent 只把确认后的错题、文法点和复习状态写回。
- 学习内容可以保留，真实聊天记录不必保存。

## 专题建议

- 知识地图节点保持稳定 ID，来源、个人理解、争议和应用想法分栏记录。
- 创作灵感可以链接到事业项目，但不会自动生成项目任务；进入项目前由用户确认。
