# 调试与验收

## 启动失败

```bash
node -v
pnpm -v
pnpm install
pnpm dev
```

如果提示 4178 端口被占用，不要直接结束不认识的进程。可以临时运行：

```bash
pnpm dev -- --port 4179
```

## 页面有旧数据

先点击主题按钮中间的刷新圆圈。它会重新读取首页摘要和当前模块。前端代码刚更新时，再使用浏览器重新载入。

## 图片或音乐缺失

确认 `Infans_Support` 和 `Infans_Studio` 同级，目录名没有改变。Support 缺失不会导致所有页面崩溃，但馆藏封面和音乐会不完整。

## 原件链接打不开

安装 Obsidian，并把该资料库命名为 `Infans_Studio`。如果使用别的名称，需要同步调整工程中的 Obsidian 链接配置。

## 手机打不开

- Mac 不能只运行默认 `pnpm dev`，应临时使用 `pnpm run dev:lan`，或配置私人 HTTPS 网络。
- 确认 Mac 和手机在同一可信网络，Mac 防火墙允许连接，Mac 没有睡眠。
- `127.0.0.1` 在手机上代表手机自己，不代表 Mac。

## 外部项目没有出现

- `事业顺利_总览.md`、`project-sources.local.json` 和外部 `.infans/project-hub.v1.json` 必须使用同一个项目 ID。
- 本机配置里的 root 必须是绝对目录。
- `.infans` 清单里的来源必须是项目内部相对路径，且只允许 Markdown、JSON、YAML。
- 点刷新圆圈后看事业页的警告。

## 修改后的最低验证

```bash
pnpm check
pnpm build
```

随后在浏览器检查：首页、事业、日程、日本活动、日语、专题、游戏、动漫、资产折线图、工作日志、对话日志、异常雷达、音乐、续费和菜单。

技术检查通过不等于使用者已经验收。界面、文字和真实工作流仍需要本人看过。
