# 清洁版迁移清单

## 迁移方式

采用“完整复制原工程 → 在副本内删除不需要的模块 → 用虚构内容替换个人数据 → 构建和浏览器验收”的方式。没有单独重写另一套前端；原项目保持不动。

## 已保留

- 原版前端壳、侧栏、首页、双主题、响应式布局和原有页面视觉。
- 日程安排、事业顺利、身心健康、语言学习、金融资讯、专题研究、艺术馆藏、资产管理、实用工具。
- 小秘书清洁项目，以及项目注册、稳定 ID、项目总览、进度与待办原件、派生视图的治理方法。
- 日本活动卡、官方来源和经过脱敏的攻略。
- 日语模块及绝大多数非隐私专题学习内容。
- 游戏与动漫馆藏、必要封面；删除平台个人主页与账号字段。
- 资产和美股折线图功能，全部使用虚构账户、收支与持仓。
- 工作日志、演示对话日志、异常雷达、本地音乐、续费到期、甜品菜单。
- 通用后台服务与自动化任务说明：工作台常驻、每日日志收口、项目索引、金融简报、学习快照、到期检查与定期回顾。
- 普通日间与夜间主题所需的必要素材。
- 同级 `Infans_Support`：金融资讯资料入口、动漫封面和本地音乐样例。

## 已替换为假数据

- 人物称呼、日程、今日事项、事业项目、项目进度、收入支出、账户、银行卡尾号、美股持仓、续费日期、日志和菜单订单。
- 事业场景使用月蔷薇洋装、白鸢直播间、糖霜庭院、晨露农场。
- 真实个人称呼统一移除；历史项目名改为演示项目名。

## 未迁移

- 身份档案、真实住址、账号、银行卡、账单、凭据、密钥、真实投资记录。
- 即时通讯、多人会话、关系记忆、角色兴趣、历史附件和模型接入。
- 相册、视频、私人媒体、NAS 管理、NAS 监控、VPN/Tailscale 配置。
- 原设备路径、主机名、局域网地址、自动备份，以及原作者实际安装的 launchd 任务、脚本、模型绑定与运行日志。只保留可在新 Mac 上重建的通用说明。
- 外部项目的真实代码仓与路径；只保留治理接口和虚构示例。
- 多余主题人物、场景、聊天立绘和媒体素材。

## 验收口径

- `pnpm check` 与 `pnpm build` 通过。
- 首页、事业、日本活动、游戏/动漫、资产折线图和六个实用工具可在浏览器打开。
- 隐私扫描不出现原作者姓名、旧 Vault 地址、Mac 绝对路径、邮箱、私钥/API key 或账号型长数字。
- 所有真实数据断开，演示状态明确可见。
