# 宠物、价格追踪与东京活动

这一组功能来自另一个个人工作台 Hestia，移植进 Infans 时沿用了它的做法：**脚本抓网页，模型只摘录，脚本逐字核对**。模型交回的价格、标题、链接如果不在网页原文里，一律丢弃。

## 先准备

- 安装 Claude Code 并登录（终端里 `claude` 能用）。后台任务通过它调用模型，用的是你自己的 Claude 订阅额度。
- 工作台开着（`pnpm dev`）时，定时任务才会按时运行。错过的时刻，下次打开工作台时补跑最近一次；第一次启动不补跑。
- 「实用工具 · 设置」里可以全部暂停、单独开关、改时刻、选模型。

## 宠物

一级入口「宠物」，只读页面。记录由你或 AI Agent 写成 Markdown：

```text
80_生活事务/宠物/<宠物目录>/
├── 档案.md                         一份
├── 护理/<YYYY-MM-DD>-<slug>.md      一次一份
└── 用品/<slug>.md                  一款一份
```

`档案.md`：

```yaml
title: 团子          # 名字
species: 猫
breed: 英国短毛猫
sex: male            # male | female
neutered: true
birthday: 2022-04-12 # 可选
adopted: 2022-07-01  # 可选，到家日期
```

`护理/` 每条：`title`、`date`、`kind`（deworm 驱虫 / vaccine 疫苗 / nail 剪指甲 / bath 洗澡 / groom 美容 / checkup 体检 / illness 就医 / weigh 称重 / other），可选 `product`、`vet`、`cost`、`weight_kg`、`next_due`。正文写当次情况。

`用品/` 每款：`title`、`kind`（food / treat / litter / toy / med / other）、`status`（using 在用 / tried 试过 / stopped 停用），可选 `brand`、`started`、`rating`（1–5）。

页面会画体重曲线，并列出两周内到期的护理：每类护理只看最近一次的 `next_due`。`next_due` 只是记录，不会自动建待办。`status`、`rating` 属于判断，改动时在正文末尾追加一行修改记录（见 AGENTS.md「数据纪律」第 5 条）。

## 价格追踪

「实用工具 · 价格追踪」。两种登记，都可以在页面上直接新建：

- **指定商品**：填商品链接就追踪那一页；不填链接，就按名称在选中的站点搜索，由模型判断哪些结果是同款。名称对应多件不同商品时，页面会列出候选让你选一件，之后按它比价。
- **类别搜索**：比如「猫砂」，每次列出各站前几名，按你写的比较方式给出建议。

数据：

```text
80_生活事务/价格追踪/
├── 商品/<slug>.md            登记（手写或页面新建）
├── 类别搜索/<slug>.md
├── 原始观测/                 每次运行追加，脚本产物，不要手改
└── 派生/                     搜索词缓存、同款候选、买不买的建议；可删，下次运行会重生成
```

到手价 = 售价 + 运费 − 积分。运费没写时按 0 算并标「运费未知」。

## 东京活动

「日程安排 · 日本活动」。原来手写的活动卡照旧，另外每周按 `80_生活事务/出行攻略/活动来源.md` 自动采集：

- 来源页与类别在 `活动来源.md` 里改；勾选哪些类别、各类别的入选标准，在设置页改。
- 卡片右上角：心形是「想去」，眼睛是「不感兴趣」，后者会把卡片收起来。
- **攻略只在点「生成攻略」时才做**：脚本抓这个活动的官方页面，模型只根据页面写，页面没写的会标「官方页面未写」。生成的攻略放在 `出行攻略/AI攻略/`，出发前请再核对官方信息。
- 来源页必须是脚本能直接抓到的静态页面。靠 JavaScript 渲染的站点抓不到活动（例如 connpass 的搜索页）。

## Token 统计

「实用工具 · Token 统计」只算 Claude：

- 本机 Claude Code 的会话日志（`~/.claude/projects/`），按模型、按项目汇总；
- 工作台后台任务自己的调用账本。

给出最近 5 小时、今天、7 天、30 天的用量，方便你看会不会碰到订阅的用量上限。只算 token，不折算金额。

## 怎么省额度（20 美元订阅也够用）

- 摘录、搜索词、同款判定这些低级任务用 Haiku，并关掉思考；只有每天一次的买不买建议和你点的攻略用 Sonnet。两者都能在设置页改成 Haiku。
- 价格追踪：填了搜索词就不再让模型想搜索词；全部失败的那次不请模型给建议；每次运行最多调 60 次模型、45 分钟。
- 活动采集：来源页文字和类别都没变就不再请模型；每次最多补 15 个详情页、调 50 次模型。
- 疑似额度用尽：本次余下的调用全部停下，定时任务暂停 5 小时（设置页可以手动解除）。
- 同一个任务重复点「立即运行」，或手机和 Mac 同时点，只会运行一次。

实测参考（Haiku，关思考）：楽天搜索一个商品约 3.5 万 token，其中大部分是网页原文；一份攻略（Sonnet）约 8 千 token。

## 排障

运行状态都在 `00_本地工作台/运行状态/`（不进 git，可以整个删掉）：

```text
receipts/<任务>.json     最近 50 次运行的结果
logs/<任务>.log          最近一次运行的输出
runs/<任务>/<时刻>/      每次调用的页面文字和模型输出，保留 7 天
ai-calls/<月份>.jsonl    每次模型调用的 token
quota-hold.json          额度暂停到什么时候
```

在终端手动跑一次（在 `00_本地工作台/app` 下）：

```bash
node scripts/run-job.mjs prices
```

```bash
node scripts/run-job.mjs events
```
