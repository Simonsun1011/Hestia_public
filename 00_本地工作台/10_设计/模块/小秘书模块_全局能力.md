# 小秘书模块 · 全局能力

## 全局能力｜ID：global

> 在所有页面都能使用的入口与操作。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `global` |
| 产品边界 | 只放跨页面入口和壳层能力；任何属于具体业务页面的功能必须回到所属模块。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细
#### 玄夜与晴岚主题｜ID：global-themes

- 主题边界
  - 玄夜与晴岚只切换色彩、材质和场景背景，不复制页面布局，也不改变标题与正文的信息层级。
  - 主题选择只保存在当前浏览器；排版语义是整个小秘书工作台的共同产品契约，不属于个人可调偏好。
- 排版语义
  - 页面标题和卡片标题使用宋体回退链；正文、眉题、辅助文字与控件使用苹方回退链；时间、价格、比例、时长等数据使用 Georgia 回退链。
  - 全局按眉题、辅助文字、正文、卡片标题、重点卡标题、页面标题定义字号、字重、行高和字距；组件只选择语义角色，不在单张卡片中另造一套字号。
  - 同一级别标题必须共用组件和视觉基线；只有信息架构明确的主卡可以高一级。阅读器、刷新传书框等有独立媒介语义的场景可使用专用字体链。
- 设备顺序
  - iPad 触摸宽屏是首要排版对象，内容优先占满可用宽度；Mac 外接 4K 保留稳定信息密度和右侧人物留白；手机保证可读、可操作且无整页横向溢出，允许首屏密度不同。

#### 当前页面重新载入｜ID：global-page-reload

- 明确入口
  - Mac 与侧栏形态的 iPad 使用侧栏底部主题胶囊中央圆环；iPhone 与窄屏 iPad 使用“更多”面板内同一主题胶囊的中央圆环。
  - 圆环是独立的 44×44px 触控目标；视觉圆环只使用低对比度中性细线，不使用玄夜／晴岚主题色描边、外发光，也不把胶囊拆成三个同等分量的按钮。
  - 单击圆环立即刷新，不设置准备态或第二次点击窗口。
  - 首页品牌、桌面导航与手机底部导航只负责回首页；已经在首页时再次点击回到页面顶部。
  - 不使用头像、首页、长按或原生 `dblclick` 作为刷新入口；浏览器标准 `示例原件` 仍可用。
- 刷新语义
  - 重新载入前明确保存当前路由、已登记页面状态与阅读位置。
  - 先检查当前作用域是否已经登记 service worker；有则先请求更新检查，没有则直接继续。
  - 调用浏览器当前页面 reload，保留现有路由、查询参数与 hash。
  - 只重新载入前端页面，不声称也不尝试重启 Node 服务、小秘书.app 或 Safari Web App 进程。
  - 新页面挂载后在屏幕中央显示约 2.35 秒的古典武侠 RPG 传书框：当前秘书专用立绘从框左侧探出，右侧使用 `FZKai-Z03 → Kaiti SC → STKaiti` 楷体回退链显示“{当前值班秘书名}已经刷新啦～”。姓名和立绘路径均读取统一秘书档案，切换秘书后同步变化；一次性会话标记消费后立即清除，降低动效时保留静态框但不播放进出场动画。

#### 设备内页面位置记忆｜ID：global-page-position

- 保存范围
  - 只保存在当前浏览器、当前站点来源，不写 资料库，也不跨 Mac、iPad、iPhone 同步。
  - 只保存受控页面路由、稳定项目或功能 ID、Wiki 展开祖先和有限滚动位置；不保存搜索词、正文、对话或 AI 参数。
- 恢复规则
  - 刷新或再次打开时先等待路由、异步数据与目标布局就绪，再按可见锚点优先、像素位置兜底恢复。
  - 每次导航最多一次主恢复和一次有界校正；恢复期间暂停位置写回，结束后清理锁和计时器，避免恢复与写回循环。
  - 主动导航优先于旧记录；稳定 ID 失效时清理旧值并退回有效入口，不反复抢回旧页面。

#### iPad 切页稳定性｜ID：global-ipad-route-stability

- 点击一级目录后先在后台准备目标页面分包、分区数据与场景背景；准备期间保持当前页面可见、可滚动，不让空白骨架提前占据主区。
- 目标准备完成后一次性切换活动页；侧栏以“…”标记正在准备的目标。连续点击不同目录时只提交最后一次，较早请求晚到不得覆盖当前选择。
- 首页与当前页的保活总量继续不超过两页；缓存页使用 `display:none`，位置恢复只调整滚动，不隐藏活动页。

#### 主侧边栏显隐｜ID：global-sidebar-visibility

- 大屏入口与行为
  - 左上美宁小人只负责切换主侧边栏，不再承担刷新；单击即隐藏，隐藏后再次单击即恢复。
  - 隐藏时从壳层移除侧栏轨道，正文与场景背景同时回到第一列并占满释放出的宽度；所有导航分组、标题、页脚与占位必须一起消失。
  - 隐藏态只保留可拖动的美宁小人；轻点恢复侧栏，移动超过阈值才开始拖动且松手不得误恢复。触控目标不小于 44×44px，并提供“显示/隐藏主侧边栏”的文字化无障碍名称。
  - 不使用屏幕边缘滑动、拖拽或多击手势，避免与 iPad 系统返回、多任务和分屏手势冲突。
- 尺寸与状态
  - 只在显示桌面主侧边栏的大屏布局生效；窄屏继续使用既有底部导航，不显示额外悬浮小人。
  - 横屏、竖屏和分屏均把恢复入口约束在四边安全可视区域；默认停在左侧居中，拖动位置按可用视口比例保存，旋转或分屏后重新换算且不得越界。阅读层和其他全屏覆盖层继续盖在恢复入口上方。
  - 显隐选择与小人位置保存在当前浏览器；存储不可用时只保留本次页面会话，不阻断操作。
  - 不在侧栏空白区保留连续多击或其它隐藏手势；该区域留给未来明确功能。
  - 头像快速连点只允许第一次改变侧栏；短暂冷却后才可再次显隐，避免整页布局反复切换。
  - 工作台壳层禁止把连续触碰升级为双点整页缩放或边界橡皮筋回弹；头像本身不参与浏览器页面手势，正常单指滚动与双指缩放仍保留，避免 iPad 上背景与侧栏底部一起抖动。
