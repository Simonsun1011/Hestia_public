# 小秘书模块 · 艺术馆藏

## 艺术馆藏｜ID：library

> 浏览真正影响过 拥有者 的作品与个人收藏原件。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `library` |
| 产品边界 | 策展和阅读作品原件；分类、筛选和阅读状态不改变作品正文。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细
#### 影响过我的作品｜ID：library-influences

- 浏览入口
  - 游戏页默认先进入“影响过我的作品”
  - 按作品卡浏览真正影响过 拥有者 的个人文化种子
- 卡片内容
  - 显示作品名称
  - 保留本人原始判断
  - 每件作品只带一个“想一想”的回忆问题
- 使用边界
  - 不展示补录状态或流转状态
  - 不强制把作品继续串到研究专题或事业项目

#### 游戏库｜ID：library-games

- 收录范围
  - Steam 游戏与非 Steam 游戏在同一游戏库浏览
  - “影响过我的作品”与完整游戏库保持同级入口
- 查找与排序
  - 按游戏平台筛选
  - 按游玩时长排序
  - 通过搜索快速定位游戏
- 作品查看
  - 以卡牌方式浏览游戏记录
  - 点开后读取对应馆藏原件

#### 动漫与影视｜ID：library-screen

- 媒介划分
  - 动漫因数量和创作关联单独成类
  - 电影、剧集和纪录片合并为影视入口
- 查找方式
  - 按媒介筛选
  - 按作品名称搜索
  - 从卡牌进入作品记录
- 记录内容
  - 查看本人感受与判断
  - 保留值得以后再想的回忆问题
  - 需要时继续阅读全文

#### 动漫与影视私人馆藏｜ID：library-anime-archive

- 三种浏览方式
  - “动漫库／影视库”只负责纯展示与筛选，不承担个人判断
  - “影响我的”只展示 拥有者 明确说过影响在哪里的作品，不根据观看次数、年份或文化卡存在与否推断
  - “我的推荐”只展示 拥有者 明确说过喜欢或值得推荐的作品，并显示已经留下的简短理由
  - 年份按每五年一个区间显性分章，年份区间、类型、地区与观看状态同时作为库内筛选标签，不再各占一个顶层视图
- 卡片边界
  - 普通卡只显示封面、标题与必要的地区／类型信息；观看状态不写进卡片，右上角不显示爱心
  - 普通卡片不放简介、评分、操作按钮或详情页入口
  - 卡片宽高固定；标题超出卡内一行宽度时自动横向循环，短标题保持静止，悬停或键盘聚焦时暂停，不因标题换行改变卡片尺寸
  - 已有文化卡与本人原始判断只在“影响我的／我的推荐”出现，不混入普通馆藏卡片正文
- 数据边界
  - 年份、主类型、推荐与影响标记继续写在动漫／影视馆藏 Markdown 原件中，工作台只解析和展示
  - 外部资料只用于核对年份与作品类型，并保留确认来源；推荐、喜欢理由与影响关系不由外部资料或 AI 代写
  - 动漫封面原件与来源清单存放在支持库 `示例原件`，不进入 资料库、Git 或公开构建
  - 工作台只按清单中的稳定条目编号读取图片，不接收网页传入的本机路径；图片缺失或读取失败时继续显示本地抽象封面

#### Markdown 全文阅读｜ID：library-reader

- 工作台阅读
  - 点开馆藏条目后在工作台内阅读 Markdown 全文
  - 保留原文标题、分节和正文层次
- 往返导航
  - 关闭或返回后回到原来的馆藏分类
  - 保留打开 Obsidian 原件的入口
- 原件边界
  - 阅读器只读取 资料库 原件
  - 分类、筛选和阅读状态不改写作品正文
