# 小秘书模块 · 原生应用

## 原生应用｜ID：native

> 用小秘书原生程序承载浮动值班角色和工作台窗口；历史工程名与路径继续兼容，不再作为现行产品文案。

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `native` |
| 产品边界 | 承载浮动宠物和原生工作台窗口；网页功能仍由工作台前后端负责。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细
#### 浮动宠物｜ID：native-pet

- 启动方式
  - 普通打开小秘书时先显示宠物，再打开或切回工作台
  - 登录常驻使用仅宠物模式，不提前启动服务和主窗口
  - 主动退出后不会被反复自动拉起
- 桌面表现
  - 使用透明、无边框的浮动窗口
  - 不激活应用、不抢键盘焦点
  - 跨桌面与全屏 Space 显示
- 移动与位置
  - 拖动超过阈值后只移动，不误触打开
  - 拖动位置保存在本机
  - 显示器布局变化后自动夹回可见区域
- 右键操作
  - 打开工作台
  - 暂时收起宠物
  - 退出小秘书

#### 工作台窗口｜ID：native-window

- 按需打开
  - 点击宠物播放启动动作
  - 服务未运行时按需启动本地工作台服务
  - 在原生 WKWebView 主窗口打开工作台
- 窗口复用
  - 已有窗口时直接激活原窗口
  - 已在全屏 Space 时切回原 Space
  - 重复点击不创建第二个进程或窗口
- 入口一致
  - Dock、Finder 和浮动宠物都进入同一个小秘书应用
  - 网页路由、数据读取和业务权限仍由工作台前后端负责
- macOS 标准编辑
  - 原生菜单向 WKWebView 转发撤销、重做、剪切、复制、粘贴与全选命令
  - 普通网页文字只能选中和复制；剪切、粘贴及撤销／重做只由当前可编辑控件响应

#### 宠物状态动画｜ID：native-animation

- 动画状态
  - 待机
  - 悬停
  - 点击启动
  - 说话
  - 向左拖动与向右拖动
- 播放方式
  - 待机、悬停、说话与拖动状态循环播放
  - 点击启动只播放一次，再回到当时应有状态
  - 动画在后台预读，首帧可显示后才切换
- 异常边界
  - 视频缺失、解码失败或超时时，不使原生应用崩溃，也不阻断工作台打开
  - 动画不可用时允许本次不显示；是否改用图集属于实现细节，不单独立项或验收
- 朗读同步
  - 页面发布朗读开始与结束状态
  - 只有当前值班秘书本人发声驱动其说话动画
  - 其他来访者或本人发声不驱动值班秘书动嘴
  - 这里只同步播放起止，不做逐音素口型识别
