# 小秘书模块 · 日程安排

## 日程安排｜ID：schedule

> 把今天要做的、长期在推的、近期可以去的和正在期待的，收在同一个时间入口。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `schedule` |
| 产品边界 | 以时间为线索聚合任务、战略主线、日本活动与新品发售；页面只做派生查看和受控交互，不复制可独立编辑的第二份原件。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、限时大作战、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细
#### 今日事项四象限｜ID：schedule-current

- 任务来源
  - 中央来源
    - 汇总中央当前任务区中的非事业和共享任务。
    - 中央“长期在推”不进入今日事项。
  - 项目来源
    - 汇总事业注册表中全部活跃项目的“正在做”和“下一步”。
    - 归档项目不参与今日任务汇总。
- 自动入选
  - 必须同时满足
    - 任务仍未完成。
    - 本人已经明确设为 S、A、B 或 C。
    - 任务日期与东京今天或明天有交集。
  - 窗口变化
    - 无日期和远期任务继续留在原任务池。
    - 任务到达近两日窗口后自动出现，不需要重新登记。
- 四级分组
  - S：重要且紧急，界面提示“马上做”。
  - A：重要不紧急，界面提示“计划做”。
  - B：紧急不重要，界面提示“能推则推”。
  - C：不重要且不紧急，界面提示“少做或不做”。
- 查看方式
  - 每个象限显示任务数量、时间、标题和项目来源。
  - 点击象限可单独聚焦，再次点击恢复全览。
  - 今日事项整卡可折叠；重复任务 ID 会在卡片顶部报警。
  - 页面只做查看，完成和分级回到任务所属项目操作并写回原件。

#### 全部项目待办｜ID：schedule-all-project-todos

- 四象限的今明窗口与 SABC 入选规则保持不变；其正下方用一条全宽入口内联展开全部项目待办，不使用弹窗或定高嵌套滚动。
- 只读取事业注册表中的活跃项目，严格按注册表顺序分组；每个项目内部保持“正在做”在前、“下一步”在后及原件书写顺序。只列未完成任务，不含中央任务和归档项目。
- 列表只展示任务标题、所属区块、已有日期与 SABC，不把说明子项复制进页面。
- 关注只适用于有显式稳定 ID 的项目任务。`示例原件` 写入 `示例原件`，只保存 `projectId:taskId`，不改任务原件、SABC 或完成态；缺稳定 ID 的任务仍展示但星标禁用。
- 关注文件缺失时 GET 返回空且不落盘；PUT 走持久写入身份门禁、任务存在性复核、数量上限、去重、0600 权限和临时文件原子替换。Mac、iPad 与手机通过同一服务读取同一状态。
- 小秘书只把当前仍存在、未完成的关注键与实时项目任务拼接进事业上下文；过期键不输出，也不在关注文件复制标题、日期或项目正文。

#### 月度路线图｜ID：schedule-roadmap

- 内容边界
  - 中央“长期在推”继续提供战略里程碑；各项目 `项目进度与待办.md` 的“限时大作战”提供临时高关注区间与阶段门。
  - 大作战时间条、阶段点和项目主页看板使用同一组大作战／阶段稳定 ID，不向中央长期待办复制一份。
  - 同时兼容旧复选框里程碑与事项治理后的顶层“战略主线 / 项目进度 / 日程”行；普通治理行不是可勾选待办，缩进说明不进入主线。
  - 没有未完成且带日期事项的泳道不渲染。
  - 无日期内容不凭关键词猜测时间条。
- 泳道归类
  - 行业活动优先排列，其后按游戏事业、糖霜庭院、专题课程等主线展示。
  - 显式泳道前缀优先；无法归类的事项进入“其它”。
  - 事业、修炼和生活使用三类固定色相，状态通过形态表达。
  - 限时大作战按所属项目映射到既有泳道，并排在该泳道普通事项之前；同项目有多个时，先显示正在进行，再显示即将开始。
- 事项形态
  - 阶段与区间显示为时间条，阶段条更厚。
  - 事件和节点显示星标，截止显示倒三角，决策门显示菱形。
  - 细节显示小点，例行事项在同一行显示多个星标。
  - 限时大作战父条使用金红双层框体和更厚时间条；阶段门仍用既有节点语言，避免把整张甘特改成游戏界面。
- 层级与依赖
  - 带父级的阶段子项默认收在父阶段下面。
  - 可在路线图中展开阶段查看子项。
  - 已找到的前置任务显示“承接”关系；窄屏保留文字提示。
- 查看控制
  - 支持按泳道折叠、展开，以及一键折叠或展开全部。
  - 支持回到今天，并在时间轴上显示今天线。
  - 左侧保留完整名称，过短的轴上标记不强塞标题。

#### 周排期｜ID：schedule-week

- 视图切换
  - 与月度路线图共用同一批中央长期主线，可随时切换。
  - 周排期用于按日检查近期执行窗口，不另建一套任务。
- 时间定位
  - 按东京日历日定位，区间结束日完整计入时间条。
  - 星标、截止和今天线落在对应日期中点。
  - 时间轴至少展示 8 周，并延伸到最远任务后一周。
- 滚动与阅读
  - 表头显示月份、周次和每日刻度。
  - 表头与内容横向滚动同步，纵向只滚任务区。
  - 点击“今天”将当前日期移到可视区域中央附近。

#### Apple Calendar 展示｜ID：schedule-calendar

- 日历范围
  - 读取 macOS Apple Calendar 中可编辑的普通事件日历。
  - 包含 Google、个人和“计划的提醒事项”等可读来源。
  - 排除生日、节假日类系统日历和只读订阅。
- 事件展示
  - 首页展示近两日普通约会，日程页不把约会混进主线甘特。
  - 显示事件标题、所属日历、起止时间、全天和重复属性。
  - 电影、演出、讲座、考试、预约等同时存在提前到场／签到／发券与正式开始时间时，标题必须直接写明“正式开始 HH:mm”；事件若从提前到场时间起算，还要同时写明“HH:mm 到场”，避免把到场时间误认成正式开始。
  - 外部提醒事项按自身来源显示，不会自动给 资料库 任务设置 SABC。
- 本机缓存
  - 成功读取后按东京日写入本机私有缓存，不进入 资料库。
  - 当天优先复用成功快照；跨日先展示旧快照，再静默读取新数据。
  - 手动同步、日历写入成功或强制刷新时重新读取。
  - 新读取失败时保留最近一次成功快照。
- 状态与写入边界
  - 页面区分正在读取、已连接、权限拒绝和读取失败。
  - 日程页不提供手动新建、修改或删除表单。
  - 小秘书创建日程时只写普通 Event 日历，并执行预览令牌和服务端校验。
  - 提醒事项列表只读，小秘书口中的“提醒”仍创建为普通日历事件。
