# 小秘书模块 · 首页

## 首页｜ID：home

> 每天打开小秘书时，先看到行动、事业、学习、身体和金融摘要。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `home` |
| 产品边界 | 只做跨域摘要和进入各模块的入口，不保存事业、健康、学习或金融的第二份事实。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细
#### 今日待办｜ID：home-todos

- 汇总来源
  - 读取中央当前任务区。
  - 读取事业注册表中活跃项目的“正在做”和“下一步”。
  - 合并后仍保留任务的项目来源，不生成首页副本。
- 进入条件
  - 只收录本人已经设置 S、A、B 或 C 的任务。
  - 只收录未完成且日期落在东京今天或明天的任务。
  - 无日期、远期任务和中央长期主线不进入首页待办。
- 首页展示
  - 在“日程待办”合并卡中显示精简任务标题。
  - 首页只显示竖线前的一句话标题，但“一句话”不等于“一行”。在不增加卡片宽度、不撑大首页首屏的前提下，已展示待办共用固定行高预算：1 条最多 3 行，2 条每条最多 2 行，3 条每条最多 1 行；标题较短时只占实际行数，超出当前配额才在末行省略。`ID`、工作线和其他补充说明作为备注留在原件，不进入首页摘要。
  - 首页只读，不提供勾选、分级或长文本录入。
  - 点击整卡进入日程待办查看完整四象限。

#### 事业、日语与训练摘要｜ID：home-life-summary

- 事业摘要
  - 在同一张稳定高度的项目窗中，依次手动查看小秘书、《月蔷薇洋装》与糖霜庭院；默认显示小秘书。
  - 三项状态、版本和当前推进只读取事业注册表与各项目 `项目进度与待办.md` 的派生结果，不维护首页副本。
  - iPad 横向手势、Mac 触控板横向手势和键盘左右键均可切换；卡内只保留三个克制的位置点，不显示前后箭头或“1/3”文字；纵向滚动不切换，不自动播放。
  - 点击当前项目窗进入事业顺利中的对应项目；滑动切换后抑制本次误点进入。
- 日语摘要
  - 展示当前计划进度、连续天数、今日待复习量与已学数量。
  - 展示近 7 日学习节奏。
  - 首页不再渲染“每日一句”；语言学习页和底层日语数据不因此改变。
  - 标题与同排卡片保持顶部基线；四项数据在标题下方剩余空间内垂直居中，不增加卡片高度。
  - 点击进入语言学习查看探索成就和练习入口。
- 训练摘要
  - 读取训练周表显示今日训练主题和星期安排。
  - 展示最近一次训练记录。
  - 最多先列出 4 个久未训练的肌群，并提示其余数量。
  - 点击进入身心健康查看体魄、心理和平衡详情。

#### 金融简报与公开行情｜ID：home-markets

- 市场简报
  - 展示当前市场主线和简报日期。
  - 最多列出 3 条宏观大事，每条显示对象、方向、急迫等初筛标签。
  - 另列最多 2 条 AI 热点，不与宏观事件混成滚动新闻墙。
  - 点击进入金融资讯查看完整事实、市场反应与后续观察。
- 股市行情双页
  - 两页眉题统一为“股市行情”。第一页标题为“美股看板”，并按本人指定顺序显示：纳指、NVDA、SpaceX（本地支持库DAQ: `SPCX`）、GOOGL、AAPL、MSFT、AMAT。
  - 第二页标题为“A股看板”，只从示例投资账本最新演示投资账户快照派生当前 6 项持仓标的，再读取公开行情；首页接口与界面不带数量、成本、盈亏、市值或账户金额。
  - 两页沿用重点项目窗的手动切换：iPad 横滑、Mac 触控板横向滚动与键盘左右键；不自动轮播，只显示位置点。
  - 每行显示名称、独立币种列、金额与日涨跌幅；币种字号小于金额，全表共享同一组列宽以保持纵向对齐。
  - 涨跌颜色遵循本人习惯：红跌、绿涨。
- 汇率看板
  - 展示 CNY、JPY、USD 相关汇率组合。
  - 显示最新值与本轮行情更新时间。
- 排版与跳转
  - 宽屏三栏固定 `2:1:1`，美股与汇率等宽；1260px 以下先让金融资讯独占一行，手机恢复单列。
  - 金融资讯标题与正文之间保留 10px 呼吸空间。
  - 股市与汇率右上角不显示“热力图”入口文字，点击整张卡自然打开外部行情全景。
- 更新与降级
  - 行情服务启动时预热，运行中每 300 秒刷新。
  - 实时报价失败时回退日线数据；不可用时明确显示读取状态。
  - 股市和汇率卡点击进入外部金融行情看板。
