# 小秘书模块 · 资产管理

## 资产管理｜ID：assets

> 私人查看资产、收入和支出快照，不与公开行情混读。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `assets` |
| 产品边界 | 展示 S2 资产、收入和支出快照；不进入首页、普通搜索或公开金融简报。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细

#### 资产总览｜ID：assets-overview

- 数据边界
  - 只读取清洁版假账户、假负债和假月末快照。
  - 任何真实金额、账号、银行卡或券商资料都不得复制进来。
- 页面能力
  - 汇总净资产、总资产、总负债、月末趋势和资产结构。
  - 固定汇率与实时汇率是两种展示口径，不改写原始币种数据。

#### 投资分析｜ID：assets-investments

- 组合视角
  - 用虚构美股持仓展示账户汇总、收益曲线、资产贡献和集中度。
  - 可切换单项资产查看投入、卖出回款、期末市值和累计收益。
- 可信度
  - 缺少流水或行情时明确显示数据缺口，不用猜测补数。
  - 展示功能不构成投资建议，也不连接券商账户。

#### 收入｜ID：assets-income

- 按月、季度或年度查看虚构服装销售、直播合作、甜品试营业与农场收入。
- 多月选择只聚合已存在的示例流水，未来月份不提前计入。

#### 支出｜ID：assets-expenses

- 按材料、生产、物流、设备、门店和农场投入查看虚构支出。
- 固定支出与临时账单分开，重复来源不重复计算。

#### 账单导入｜ID：assets-import

- 导入前先显示文件名、格式、日期范围和待新增条目预览。
- 只有使用者确认后才写入自己的资料目录；清洁版不附带任何真实账单。
