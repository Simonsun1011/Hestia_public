# 小秘书模块 · 语言学习

## 语言学习｜ID：languages

> 以日语为主，只读查看教材、文法和真实学习进度；具体讲解与练习由手机文字 ChatGPT／ChatGPT Live 读取原件后完成。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `languages` |
| 产品边界 | 作为日语知识与进度看板，管理探索、课程 ST 主线、词汇、文法、阅读和收藏；不在课程或文法页启动学习，正式全卷仍由独立电子考场承载。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细
#### 探索成就｜ID：languages-exploration

- 总体表现
  - 分别展示词汇、文法和正式全卷成绩。
  - 总分按词汇 40%、文法 40%、正式全卷 20% 汇总。
  - 正式全卷只取最近最多 3 场；没有正式卷时总分上限为 80%。
  - 阅读短练单独记里程，不进入探索成就总分。
- 级别进度
  - 按 N5、N4、N3、N2 分别查看词汇和文法进度。
  - 词汇基础来自 Anki 已学数与总数。
  - 文法按该级全部卡片的累计答对次数计算平均阶段。
  - 阶段使用门外汉、入门、掌握、精通四级，而不是旧 A/B/C 叙事。
- 练习入口
  - 真题练习直接进入独立电子考场。
  - 专项练习可多选 N 级后出题。
  - 错题练习可多选 N 级；未选择时默认全部级别。
- 记录与校验
  - 展示最近最多 6 次考核的日期、级别、类型和得分。
  - 错题 Markdown 与状态 JSON 不一致时在页面报警。
  - 可打开探索进度、错题集和考官规则原件。

#### 课程｜ID：languages-course

- 分册与课次
  - 探索成就和课程页读取同一份课程进度；初級、初中級和中級进入页面时默认收起，点击分册后才展开课次，不再摊开 30 张大卡。
  - 每个 ST 独立显示 LV0—LV3 或未评价；有练习记录只代表有证据，不能直接推成掌握。只有全部 ST 已评价时才显示整课保守等级。
  - 当前课程位置是《できる日本語 初中級》第 3 课「私の目標」；位置不等于掌握。
  - 官方中級预留一张“20 课 · 尚未接入”分册卡；未接入权威课名和进度前不补造内容。
- 只读详情
  - 点击课次只查看课名、Can-do、ST 目标、当前等级、证据类型和最近核验日期。
  - 本课重点只读取该课语法复习原件的 `核心语法一览` 显式表；原件列多少就显示多少，不按课文出现项扫描，也不设置人为数量。
  - 原件没有明确 ST 归属时不反向猜测；相邻知识只进入个人记录，不冒充教材重点。
- 看板边界
  - 页面不显示大段教材正文、AI 练习课文、官方答案或教材阅读器。
  - 页面不提供开始、继续、从这里练等操作；手机文字 ChatGPT／ChatGPT Live 负责具体学习。
  - 只有经 AI Agent 核验的真实练习记录才派生 ST 状态、主要卡点、下次复习和个人笔记摘要。

#### 手机 GPT Live 日语教学｜ID：languages-live-learning

- 启动与选课
  - 拥有者 在手机文字 ChatGPT 中说“开始练日语”；文字阶段先通过 Infans 只读入口读取当前课、ST、学习档案、真实错误和最近记录。
  - 每次只确认一个 ST 沟通任务，最多带一个必要辅助目标；读取、材料真实性与交接包不完整时不得先进入 Live。
- 同一聊天语音教学
  - 文字 ChatGPT 在当前聊天完整输出自包含交接包后，拥有者 再在同一聊天开启 GPT Live。
  - GPT Live 负责朗读、纠错、角色练习、真实内容替换和新场景迁移；语音阶段不假设能够调用私人 资料库。
  - 核验原文、本人当次提供的材料与 AI 教学改写逐项标注；没有原版音频时明确称为 GPT Live 朗读。
- 记录与写回
  - 结束时在聊天中输出结构化练习记录，保留提示程度、重说与迁移、仍不清楚、下次复习和 Anki 候选。
  - GPT Live 不直接写 资料库，也不直接修改 `专项掌握.json` 或错题状态；由 AI Agent 核验来源、稳定 ID 与重复记录后写回。
- 当前边界
  - 2026-08-28 的真实对话已由 AI Agent 回看并保守整理为一次正式记录：初中級第 3 课 ST1 为 LV1，相关 N4／N5 条目写入口语个人笔记；这不等于掌握，也没有修改题目进度。
  - 当前协议、交接包和模板已经支持逐知识点原句、纠正、提示、重说、迁移和下次复习；仍需下一次手机练习验证 ChatGPT Live 能否直接稳定输出新版完整结构。

#### 文法｜ID：languages-grammar

- 三个分支
  - 一级文法内部固定为“接续／句式、变形、敬语”；独立变形 Tab 退役，旧地址自动转入变形分支。
  - 在 N5 至 N2 之间切换，并保留搜索、薄弱和待复习筛选；筛选只影响浏览，不形成练习清单。
- 两条进度
  - 题目表现继续只读取 `专项掌握.json` 和正式题目证据，沿用门外汉／入门／掌握／精通口径。
  - 口语使用只读取经 AI Agent 核验的真实记录，区分未练习、提示后可用、可独立使用和后续复测稳定。
  - 两条进度互不改写；做题答对不自动等于会说，一次口语成功也不写入题目掌握。
- 卡片内容
  - 默认显示稳定 ID、名称、接续、含义、首个例句、题目表现、口语状态和复习日期；展开后查看其余例句、辨析、易错和个人口语记录。
  - 敬语分支只读取各 N 级原件明确的“敬语”组，再互斥整理为尊敬语、谦让语／丁重语、丁寧语／美化语和敬语请求／补助表达；正文中偶然出现“谦让”等字样不能把普通句式吸入敬语。
  - 页面不再提供待练购物车、全选、随机或开始专项；GPT 根据课程重点和薄弱证据组织真实练习。

#### 变形｜ID：languages-conjugation

- 该稳定 ID 只保留历史与旧链接兼容，不再代表独立一级页面。
- 变形知识卡、规则原件与题目掌握映射全部保留，并在文法的“变形”分支中展示。
- 变形口语状态由其关联文法稳定 ID 的真实记录派生；展开卡片不等于本人练习或掌握。

#### 阅读｜ID：languages-reading

- 阅读库
  - 当前读取已精校的 N2 真题阅读库。
  - 按考试场次显示篇目数和题目数。
  - 可查看全部场次，或筛选到某一场。
- 选择练习
  - 每张篇目卡显示大题、标题、正文预览和题量。
  - 点击篇目只练这一篇，不打开整套试卷。
  - “随便练几篇”从当前 N2 阅读库随机出题。
- 作答与反馈
  - 在工作台内完成阅读、选择答案和交卷。
  - 交卷后显示正确数，并可让小秘书简短讲评弱项。
- 阅读里程
  - 统计已练篇目、已练题数和近 7 日练习情况。
  - 阅读成绩只进入里程原件，不改变探索成就总分。

#### 收藏｜ID：languages-collection

- 导入
  - 接受 Language Reactor 导出的 JSON 收藏。
  - 首次导入和重新导入都先预览，再合并已有文本记录。
  - 显示最近导入时间、总收藏数、句子数、单词数和来源数。
- 浏览与筛选
  - 支持搜索原文、翻译、假名或作品名。
  - 可在全部、完整句子和带语境单词之间切换。
  - 可按内容来源筛选，并分批继续加载收藏。
- 收藏内容
  - 句子卡展示原文、读音、翻译、作品来源和时间位置。
  - 带语境单词同时展示词语与转写。
  - 有上下文时可展开查看前一句、本句和后一句。
- 数据边界
  - 只保存整理后的文本与必要来源信息。
  - 不保存音频、截图或登录 Cookie，并显示本次略过的媒体数量。
  - 收藏属于兴趣旁支，不计入日语探索成就。

#### 三模式考官｜ID：languages-exam

- 真题练习
  - 打开方式
    - Mac 本机打开独立电子考场全卷，服务未启动时由启动脚本拉起。
    - 手机通过 私有网络 私有 HTTPS 入口打开电子考场。
  - 产品边界
    - 工作台不再内嵌简化版全卷。
    - 正式全卷成绩回到探索成就参与最近三场统计。
- 专项练习
  - 选题入口
    - 可从探索成就页多选 N 级随机抽卡。
    - 文法 Tab 不再维护待练清单或提供专项启动；薄弱项只作为 GPT 读取和个性化练习的依据。
  - 作答结果
    - 页面本地完成作答和交卷。
    - 结果更新卡片累计答对、LV 与错题状态。
- 错题练习
  - 出题范围
    - 只读取仍处于活跃状态的错题队列。
    - 可按一个或多个 N 级筛选后开考。
  - 数据边界
    - Anki Hard 不会被当成工作台错题补入。
    - 已退出活跃队列的错题不再进入错题练习。
- 考试界面与小秘书
  - 响应式布局
    - 桌面考试时试卷主区让出小秘书侧栏，并尽量铺满剩余区域。
    - 手机考试时小秘书使用底部半屏抽屉。
  - 讲评边界
    - 小秘书可在交卷后旁评与讲评。
    - 小秘书不会在聊天中代替本人作答。
