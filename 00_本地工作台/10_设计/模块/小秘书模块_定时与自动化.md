# 小秘书模块 · 自动化方法

## 自动化方法｜ID：automation

> 在固定时间更新明确白名单内的快照、简报与回顾。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `automation` |
| 产品边界 | 只运行已经登记的定时任务；每项任务必须有明确事实源、写入目标和失败边界。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细

#### AI 自动验收｜ID：automation-ai-acceptance

- 已有任务按稳定 ID 继续推进；新需求先在项目管理原件注册任务，再开始执行。
- AI Agent 完成后先验证工程事实；需要使用者主观判断时标记为待验收，不自动宣称稳定。
- 遇到缺权限、缺资料、外部服务失败或结论冲突时写回阻塞、证据和下一步。
- 清洁版只记录这套方法，不自动安装后台轮询或定时任务。

#### 金融简报｜ID：automation-market-brief

- 当前简报与历史归档分开；换日时先保留上一份，再生成新简报。
- 只处理公开金融资料，不读取投资账户或个人交易记录。

#### 定期检查｜ID：automation-checks

- 将检查项分成日常、每周、每月和按需复核，并写清条件、证据和失败处理。
- Mac 备份只提供手动或可选自动化方法，由使用者自行决定是否启用。
