# 小秘书模块 · 专题研究

## 专题研究｜ID：topics

> 用少量长期母题承接持续研究；知识地图是唯一前台导航，课程、作品和笔记作为节点来源原件。

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `topics` |
| 稳定路由 | `示例原件`；旧 `示例原件` 和 `domain=classical-chinese` 只做兼容回落 |

| 项目推进 | 任务、状态和验收仍以 AI 协作系统项目管理原件为唯一原件。 |

### 功能明细
#### 手机 GPT Live 专题教学｜ID：topics-live-learning

- 文字阶段读取
  - 从八个真实母题逐层定位到唯一 `nodeId`，读取节点正文、来源、内容状态和已有本人学习记录。
  - 文字 ChatGPT 必须在同一聊天完整输出本次交接包；只说“语音会知道”不算完成交接。
- 手机语音教学
  - 拥有者 在同一聊天开启普通手机 GPT Live；语音阶段只使用已经写进聊天的上下文，不假设 Live 能直接调用私人 MCP。
  - 围绕一个认知任务讲解、追问、举例，并按需要做概念区分、反例、教回或新案例迁移；没有完成的检验如实保留。
- 记录与单写
  - 结束时输出带稳定记录 ID、`nodeId`、本人表达、AI 整理、未解决问题与下一入口的待入库记录。
  - GPT Live 不直接写 资料库；AI Agent 核验来源、重复记录与归属后，把证据写回同一知识节点和对应学习记录。
- 证据边界
  - 已有真实 GPT Live／ChatGPT 学习记录证明流程能产出可核验票据，但不等于节点掌握或整个知识地图内容完成。
  - 当前协议保持 `building`，待更多母题完成真实手机教学、教回和迁移后再收为稳定。
