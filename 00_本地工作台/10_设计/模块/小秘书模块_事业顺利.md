# 小秘书模块 · 事业顺利

## 事业顺利｜ID：projects

> 统一查看现实项目、项目任务与产品能力。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `projects` |
| 产品边界 | 只管理项目组合、项目进度和产品功能导航；工程设计、测试与发布事实仍留在各项目原件。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、限时大作战、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细
#### 限时大作战｜ID：projects-focus-battles

- 概念边界
  - 限时大作战是项目进度内部的临时执行结构，不是新项目、单个待办、里程碑或第二套任务系统。
  - 它回答“最近为什么高度聚焦、这几天按什么节奏解决什么问题”；SABC、今日事项、里程碑、项目待办和功能 Wiki 继续承担原职责。
  - 当前日、总天数、是否即将开始／进行中／到期由东京日期派生，不要求每天改原件。
- 唯一原件与关系
  - 每个项目只在自己的 `项目进度与待办.md` 维护 `## 限时大作战`；工作台主页、甘特和关系索引都是派生视图。
  - 大作战、阶段、任务和功能均使用稳定 ID。阶段可引用多个任务和功能，也可按阶段 ID 显式登记依赖。
  - 任务文本、SABC、完成状态仍由项目任务行单写；功能定义和成熟度仍由产品功能 Wiki 单写；大作战不得复制它们的事实。
- Agent 操作边界
  - 小秘书只做看板，不提供手动新建、编辑、暂停、延期或删除表单。
  - 拥有者 与 Agent 对话确定名称、期限、目标、阶段和关系后，Agent 先展示变更摘要，再按稳定 ID 写入项目原件。
  - 删除优先改为已取消并保留追溯；只有 拥有者 明确要求清除原件时才执行真实删除。
- 展示
  - 同一大作战原件按三种密度派生：事业页顶部只用三列紧凑状态卡显示项目名、大作战名和完成百分比，项目主页顶部是完整作战看板，功能 Wiki 顶部是紧凑摘要条；三处不复制或另存计划。
  - 事业页只在存在进行中或即将开始的大作战时出现总览区，每场一张横向进度图；项目主页最多显示一个展开主看板和一个紧凑并行项，更多计划只显示数量并从归档查看。
  - 小秘书与已有外部完整项目一样先进入项目主页；项目主页汇总当前第一步、任务、阻塞、最近完成、跨项目关系与功能 Wiki 入口，深链接仍可直接进入 Wiki。
  - 看板以“作战令”双层描边和阶段路线作为唯一强视觉；可以点阶段展开真实任务、交付物和完成门，可以跳到功能 Wiki 或甘特，不提供编辑按钮。
  - 甘特把大作战作为所属泳道／项目中的第一行，用金红外框和加粗阶段条高亮；主页和甘特使用同一大作战与阶段 ID。
- 生命周期
  - 已启用计划在开始日前显示“即将开始”，起止窗口内显示“进行中”；已暂停、已完成、已取消或到期计划退出展开看板并进入可回看状态。
  - 提前完成记录真实完成门与证据后立即退出顶部；延期必须保留原结束日期的调整记录，不静默改期。
  - 技术完成、设备链路、Agent 验收和 拥有者 主观验收分开记录，不因阶段通过自动把功能状态改成稳定。

#### 项目关系网｜ID：projects-relation-graph

- 节点和权威
  - 项目、工作线、模块、功能、任务、阻塞和最近完成都使用稳定 ID。
  - 任务、阻塞与完成事实及其显式关系仍由所属项目 `项目进度与待办.md` 单写；工作台索引和页面都是派生视图。
  - Project Hub 只登记外部项目的工作线、功能树和安全原件入口；`taskLinks` 与 `recentLinks` 只作 v1 兼容输入，不得成为第二份关系真值。
- 关系类型
  - `父级`只表达层级，不自动表示依赖、相关或阻塞。
  - `工作线`、`模块`和`功能`表达一条记录的范围，均允许多值。
  - `关联任务`表达普通多对多引用；`依赖`表达必须先完成的前置；阻塞记录通过`关联任务`指明当前真正被卡住的任务。
  - 最近完成通过`关联任务`表示为哪些任务提供近期上下文；只有最近完成与任务沿用同一个 ID 时，才表示任务本身已经完成。
  - 阻塞和最近完成可同时关联多个任务、工作线、模块或功能；一个任务或功能也可被多条记录引用。
- 范围查询
  - 记录所在的项目原件天然提供项目根范围；项目根显示项目全部已映射记录和没有子层级归属的项目整体记录。
  - 工作线显示直接关联项，并向下聚合其功能树的模块和功能。
  - 大模块聚合自身与全部后代功能；小功能只显示自身及后代节点的显式关系。
  - 没有明确映射的记录只出现在“项目整体／尚未分类”，不自动混入每个模块。
- 任务开工与收尾
  - 开工时登记或复用稳定任务 ID，并至少写一个项目、工作线或功能范围；跨项目时使用被引用原件中的全局稳定 ID，不复制任务。
  - 收尾时的最近完成沿用原任务 ID 或用新稳定 ID 并写`关联任务`；受阻时的阻塞记录必须指明被阻塞任务或明确的功能／工作线范围。
  - 不能唯一判定时，AI 先生成带依据和置信度的推荐；只在 拥有者 确认后写入，不得用标题或关键词自动猜测正式关系。

#### 外部项目主页｜ID：projects-external-hub

- 入口层级
  - 外部完整项目的项目卡先进入项目主页，不把整个项目误当成一棵产品功能树。
  - 项目主页展示清单中真实登记的工作线；没有证据的状态不由工作台补造。
  - 只有明确登记为产品功能树的工作线，才进入现有 Wiki 功能树页面。
- 薄契约
  - 项目目录只需维护独立的 `示例原件`，解析器不猜任意 Markdown 标题。
  - 契约只约束稳定 ID、关系、状态、原件引用、任务/近期完成关联和版本。
  - 详细设计正文的标题、章节顺序、篇幅、文风和思考过程不受工作台约束。
- 末端事实
  - “具体功能”的末端条目可点开或用键盘展开，不依赖悬停。
  - 展开区只呈现清单已有的完整说明、状态和来源；没有说明或来源时不编造。
  - 普通产品沿用同一通用展示，不强塞游戏专属字段；schema v1 不变。
- 只读安全
  - 服务器只按已登记项目 ID 命中固定外部根，前端不能提交任意目录。
  - 拒绝绝对路径、`..`、反斜杠、符号链接逃逸、凭据、环境文件、`.git`、构建缓存和运行日志。
  - 页面只显示原件标签和通过校验的项目内相对路径，不下发外部绝对根；外部根、清单或单个原件不可用时局部降级。
- 兼容边界
  - 小秘书自身继续从项目卡直达现有产品功能 Wiki 树。
  - 没有外部项目清单的既有项目继续使用普通项目详情或旧功能树，不要求迁移。

#### 事业项目组合｜ID：projects-portfolio

- 项目登记
  - 从事业注册表读取项目名、状态、稳定项目 ID 和项目管理原件。
  - 活跃项目进入日常聚合；归档项目单独列出，不参与当前任务汇总。
  - 未立项储备不作为正在推进的项目展示。
- 固定层级
  - 小秘书作为首要项目占据主卡。
  - 月蔷薇洋装和糖霜庭院保持第二层重点位置。
  - 其他游戏、自媒体和事业项目按既定经营优先级排列，不按更新时间重排。
- 进入项目
  - 点击项目卡使用注册表中的稳定 ID 打开详情。
  - 项目卡只展示短状态和少量正在做事项，长文不改变组合布局。
  - 缺少管理原件时明确提示尚未迁入或文件缺失，不从历史记录补造状态。

#### 项目当前状态｜ID：projects-status

- 状态总览
  - 读取项目管理原件中的“当前状态”短结论。
  - 项目主页把“当前第一步”收进项目总看板右侧；普通挑任务页与非小秘书的功能树继续使用独立位置。先取“正在做”的第一条未完成任务；没有时取“下一步”的第一条未完成任务；两边都没有时明确显示“尚未指定当前第一步”。
  - 当前第一步沿用任务原有的 SABC、日期、所属区块、完成操作与原件入口，不保存新字段，不按优先级、日期或最近完成重新排序。
  - “正在做”和“下一步”分别展示，不把两者合并成流水账。
  - 没有可验证任务时显示“无”或空状态，不从最近完成反推待办。
- 风险与进展
  - “项目阻塞”单列当前卡点，并与任务、工作线、模块和功能使用稳定 ID 显式关联；一个阻塞可关联多个任务或功能，同一任务或功能也可对应多个阻塞。
  - “最近完成”只读已记录事实，并按当前选中的层级过滤展示；一个完成记录可关联多个任务或功能，同一任务或功能也可对应多个完成记录。
  - 查看产品根节点时，最近完成按大模块分组；没有模块归属的内容进入“项目整体”。
- 权威入口
  - 可打开项目设计、工程、测试或管理原件。
  - 产品类项目可以从权威入口登记自己的产品功能树。
  - 页面摘要不替代这些事实原件。

#### 项目任务写回｜ID：projects-task-writeback

- 已有任务操作
  - 未完成任务可直接标记完成。
  - 已完成任务可恢复为未完成。
  - “相关任务”中的已完成项仅在有可信完成时刻且未满 24 小时时暂留；恰好满 24 小时即隐藏。旧任务没有完成时刻时不拿计划日期或当前时间补造，直接从看板隐藏，原始任务仍保留。
  - 页面同时显示任务日期和所属项目；没有日期时明确标记“未定日期”。
- 定位原件
  - 通过来源路径和稳定任务 ID 找到唯一任务行。
  - 缺少稳定 ID 的任务保持只读，并提示先回原件补 ID。
  - 重复 ID、路径越界或来源不在注册表时拒绝写入。
- 写入保护
  - 操作携带预期完成状态，提交时检查原件是否已被外部修改。
  - 写入先走预览，再由受控写入接口提交到来源文件。
  - 预览过期或状态冲突时停止写入并要求刷新。
- 新增任务边界
  - 项目详情不提供长文本“新增任务”表单。
  - 新任务由小秘书对话或对应项目 Agent 发起，并继续写入项目管理原件。

#### SABC 任务强调｜ID：projects-sabc

- 四级含义
  - S：重要且紧急。
  - A：重要不紧急。
  - B：紧急不重要。
  - C：不重要且不紧急。
- 调整方式
  - 未分级任务显示 S、A、B、C 四个按钮，由本人手动选择。
  - 点击其他等级直接切换，不需要先清空。
  - 再次点击当前等级即取消分级。
  - 工作台不根据日期、文字或紧迫感自动补等级。
- 完成态
  - 任务完成后隐藏四级按钮，但在原件中保留最后等级。
  - 恢复未完成后重新显示原等级，可继续切换或清空。
- 日程联动
  - 已分级、未完成且进入东京今明窗口的任务自动出现在日程四象限。
  - 清空等级、完成任务或离开近两日窗口后，不再出现在今日事项。

#### 产品功能 Wiki 树｜ID：projects-feature-tree

- 产品接入
  - 原件登记
    - 产品项目从自己的权威入口登记一份产品功能树原件。
    - 项目没有登记功能树时继续使用普通项目详情，不生成空树。
  - 功能读取
    - 左侧树按“大模块—小模块”读取真实功能，不复制成第二套清单。
    - 支持按模块名、小模块名、说明和状态搜索。
- 状态展示
  - 单项状态
    - 稳定功能不显示多余状态标签。
    - 新增功能可显示准备开发、设计中、开发中、测试中、等待验收或已暂停。
  - 折叠汇总
    - 模块折叠时，一项待推进直接显示其状态，多项只显示数量。
    - 模块展开后由各小模块显示自身状态，不重复模块汇总。
- 详情查看
  - 选择大模块时查看包含的小模块。
  - 选择小模块时查看说明、具体功能点和开发进度。
  - 可打开当前功能原件、完整产品功能树和项目进度原件。
- 任务与近况
  - 任务关联
    - 任务通过稳定功能 ID 关联到小模块；未关联任务保留在产品根节点。
    - 相关任务继续使用同一项目原件，并可完成、恢复或设置 SABC。
    - 项目阻塞仍只在项目管理原件维护一份；查看大模块时汇总该模块的显式关联，查看小功能时只显示该功能的显式关联，不按文案猜测。
    - 阻塞或最近完成可用 `｜关联任务：<task-id-1>,<task-id-2>` 引用多个任务，并继承这些任务的功能关联；同一任务可被多条阻塞或完成记录引用。也可继续直接使用 `｜模块：...` 或 `｜功能：...`。
  - 最近完成
    - 产品根节点按大模块分组展示近期完成。
    - 选择某个大模块时只显示该模块近况。
    - 没有模块归属的完成项进入“项目整体”。
