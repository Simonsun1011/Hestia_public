# 小秘书模块 · 实用工具

## 实用工具｜ID：tools

> 把需要单独打开确认的本地工具集中在一个启动台。

### 模块卡

| 字段 | 内容 |
|---|---|
| 稳定模块 ID | `tools` |
| 产品边界 | 集中承载需要单独打开的本地工具；各工具故障只局部降级，不拖垮工作台。 |
| 功能状态 | 只在下方功能表维护；小秘书_产品功能树 只登记并读取本原件。 |
| 项目推进 | 任务、SABC、阻塞和最近完成仍以项目的 `项目进度与待办.md` 为唯一原件。 |
| 依赖与事实源 | 清洁版只保留结构与方法；实际资料由使用者自行建立。 |

### 功能明细

#### 工作日志｜ID：tools-development-log

- 按日期阅读 AI Agent 的施工摘要、修改范围、检查结果和未完成事项。
- 工作日志记录工程事实，不代替项目任务状态，也不混入日记。

#### 对话日志｜ID：tools-dialogue-log

- 保存经使用者确认导入的 GPT Live 或其他对话，保持双方原始顺序。
- 对话日志是非权威回顾；任务、健康结论和正式日记仍回到各自原件。

#### 异常雷达｜ID：tools-cron

- 日更项直接显示成功、失败或尚未执行；周期项分开显示上次结果和下次条件。
- 清洁版只用假账号、假账单和假银行卡尾号演示，不安装真实定时任务。

#### 续费到期｜ID：tools-renewals

- 按已过期、30 天内、90 天内、自动续费和日期待补分组。
- 银行卡只允许假代称与假尾号，不记录完整卡号、PIN、CVV 或支付密码。

#### 私房菜单｜ID：tools-kitchen-orders

- 显示虚构客人、来访日期、甜品、过敏原和订单状态。
- 本地快照与长期归档分开；删除前明确确认，不把管理凭据返回浏览器。

#### 本地音乐｜ID：tools-music

- 从同级 Infans_Support 的示例音乐目录读取多层文件夹。
- 支持查找、歌单、排序、顺序播放、单曲循环、随机播放和音量记忆。
- 音频保持只读；文件缺失时只让音乐页局部降级。
