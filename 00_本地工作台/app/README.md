# Infans Studio 本地工作台

这是从原 Infans 工作台直接复制并清洁后的 Mac 单机演示工程。页面结构、主题、路由和核心交互沿用原项目；人物、事业、财务、日志和日程内容均改为虚构样例。

## 启动

```bash
cd 00_本地工作台/app
pnpm install
pnpm dev
```

浏览器打开终端显示的本机地址，默认是 `http://127.0.0.1:4178/`。

## 验证

```bash
pnpm check
pnpm build
```

开发服务只监听本机回环地址。清洁版不会连接 NAS、券商、银行卡、聊天模型、私人网络或真实账号，也不预装原作者的定时任务。通用后台任务的范围和启用顺序见 `../../90_使用说明/后台服务与自动化任务.md`。
